# FestNova 🎉

FestNova is an AI-powered college event management platform.

## Features
- Event Registration
- Admin Dashboard
- Gallery Section
- Email Confirmation System
- AI Chatbot (Gemini API)
- Event Management

## Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- HTML/CSS/JavaScript
- Gemini AI API

## Installation

```bash
npm install
npm start
```

## Environment Variables

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key
EMAIL_USER=your_email
EMAIL_PASS=your_app_password
```
